# 你的随机盲评样本

抽样方式：从 12 题中按预注册固定种子等概率、不放回抽取 4 题。以下左右位置已经随机化，不显示版本、模型或来源。只需判断哪一侧更像真人正在狼人杀现场自然接话；实质相当可选“平”，事实不足可选“跳过”。

## 1. `item_076b4e71b5b88c24`

场景：第3轮仅剩6人。1号想投8号，理由是8号上警退水没解释；但1号上一轮曾用票型判断3号不是狼。3号遗言已确认女巫，8号曾与3号一起投11号。

左：

> 5号。先确认公开事实：第2轮投11号的只有3号和8号，这点1号没说错。但1号上轮自己说过“2号投3说明2与3不共边，3号非狼”——3号遗言确认是女巫，8号跟女巫投11号，在票型上是跟好人站队，不是冲票。反问1号：如果8号是狼，跟着真女巫投自己狼队友11，收益是什么？我找不到。11号夜里被刀、警徽撕毁，获利的是不用再应对1.5票警长权重的人。8号上轮敢陪3号投11，票型上反而是好人倾向。

右：

> 1号，你昨天用不共边票型替3号降低狼面，今天却突然把票口转向8号。8号上警退水没说动机，但第2轮只有3号和8号投11号，3号是女巫，8号那票是跟女巫走的。你改口投8号，逻辑链条断了吧？

## 2. `item_fa7a03c1060a214d`

场景：第1轮首置位发言。昨夜平安夜，8人都存活；白天还没有其他玩家发言。

左：

> 公开信息显示第一轮夜晚无人出局，我提一个可验证的疑点：这轮平安夜要么是守卫守中了要杀的人，要么就是狼人主动选择了空刀。大家可以聊聊自己对平安夜的看法，我先过，听听后面所有人的发言再归票。

> 呃，第一晚平安夜，信息不多啊。大家有什么看法吗？

## 3. `item_f24884dda5cb0c3f`

## 4. `item_55b5f96f24fc6a5a`
