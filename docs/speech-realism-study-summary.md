# 虚拟玩家发言真人感十轮实验复盘

日期：2026-07-19

## 结论

十轮实验没有得到可以上线的“真人感增强 Prompt”。原对局的主要问题也不是模型大量逐字复读，而是以下因素叠加：

1. 质量门禁把低整体相似度的有效台词误判为重复并清空；
2. 两次官方 DeepSeek 请求在约 10 秒时超时；
3. 同轮质量任务发生碰撞，连续玩家被要求处理相同内容；
4. 动态生成中，后手会错误引用前手观点，并把尚无再次发言机会误判为“回避回答”，随后形成集体围攻。

保留两项有确定性证据的运行态修复：收紧重复硬拒绝边界，以及全桌共享的质量任务轮转。其余口语化、人设账本、历史提醒、静态和动态 A/B 方案都不进入线上。

## 十轮结果

| 轮次 | 实验 | 结果 |
|---|---|---|
| 1 | 原始 Prompt、口语化 Prompt、一次调用内私有反应状态 | 发言更短，但自然度、人设和互动未提高；状态版更慢并产生规则冲突 |
| 2 | 人物历史、主要回应对象、交流动作和人设行为 | 综合盲评落后；“未发言记录”曾被错误当成历史立场 |
| 3 | 系统维护、模型只读的人物账本 | 状态可靠性提高，但综合盲评 15:24；约束会压过私人硬信息和当前任务 |
| 4 | 只突出本人历史原话和票口 | 总表 23:16，但真正有历史台词的场景为 2:7，正向结果来自无历史子组 |
| 5 | 预注册复现无历史防编造边界 | 关键分组 14:16，未复现上一轮事后优势 |
| 6 | 整局未发言、重复和任务碰撞审计 | 15 次请求中 10 次有台词、5 次未发言；3 次质量误杀、2 次 timeout；整句重复为 0 |
| 7 | 重复硬拒绝边界 | 只有无新命题且整体相似度不低于 0.3 才重写；历史反事实可避免 3 次误杀 |
| 8 | 同轮任务共享轮转 | 普通任务碰撞 5→0，全部碰撞 5→1，最长连续同任务 3→1 |
| 9 | 历史任务与共享轮转的静态成对生成 | 真正改变任务的样本综合偏好 7:8，未证明真人感提高 |
| 10 | 后手读取本分支新台词的动态整轮 A/B | 整轮偏好 4:2，但主题重合 58.06%→63.44%，事实依据 1:4、1 平，不通过 |

## 保留的运行态修改

### 重复质量门禁

`repeated_debate_phrase` 只有同时满足以下条件才要求重写：

- 没有识别到新结构化命题；
- 整体 lexical similarity 不低于 `0.3`。

低重合的共享公开事实仍记录 warning，但不会清空台词。真实长段复制继续触发重写；provider timeout、规则冲突和其他质量失败不受影响。

### 同轮任务轮转

普通 `round_robin` 任务使用“轮次 + 发言阶段”的全桌共享起点，再按发言位置依次轮转。`personality_id` 不再改变任务起点；人物差异仍由人设和策略 Prompt 控制。上下文触发的事实核验或反方审视覆盖规则保持不变。

## 不保留的实验方向

- 只要求“更像同桌说话”的口语化提示；
- 在一次调用中让模型自报私有反应状态；
- 外部人物账本、历史原话强化和无历史防编造提示；
- 把任务去重直接解释为最终台词真人感提升；
- 只依赖模型盲评的综合偏好决定上线。

这些方向会降低报告式措辞或提高表面回应率，但没有稳定提高自然度、人设、事实依据和可看性。动态实验还证明，紧密的回应链可能建立在错误引用上，不能把“更多点名和反驳”直接当成真人感。

## 保留的整局审计工具

整局审计读取 Replay 与 live events，分别统计未发言原因、质量重试、重复门禁、整句重复、主题重合、任务碰撞和玩家覆盖，不调用生成模型，也不修改历史数据。

在 `apps/api` 目录运行：

```bash
.venv/bin/python -m app.werewolf.speech_repetition_audit \
  --run-id run_4f52155c3bd4 \
  --output /tmp/speech-repetition-audit.json
```

`exact_duplicate_pair_count` 用于判断整句复制；同轮 bigram cosine 只表示主题或措辞趋同，不能单独作为拒绝台词的依据。`quality_exhausted`、provider timeout 和真人感必须继续分开统计。

## 证据边界

- 实验基于 `run_4f52155c3bd4` / `game_7ebbafee` 的持久化 Prompt 和 Replay，代表性有限；
- 生成模型为官方 `deepseek-v4-flash`，关闭思考模式；匿名预筛使用 `glm-5-2-260617`；
- 独立模型盲评只用于预筛，不等于人工评审；
- Round 10 首次运行曾混入历史分支的当前轮声明，该批结果已判无效并从正式结论排除；
- 当前保留修复的证据分别是确定性边界回归与历史反事实调度结果，不宣称已经在新线上对局中证明最终未发言率或真人感改善。
