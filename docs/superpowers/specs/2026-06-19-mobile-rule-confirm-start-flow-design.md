# 手机版规则确认开局流程设计

**日期**: 2026-06-19
**范围**: 调整 `apps/mobile-web` 的对局首页和自定义开局入口，让手机端先选择并确认规则，再提供快速开局和自定义开局。

## 1. 结论

移动端对局首页改为规则优先流程：

1. 用户先在首页选择规则预设。
2. 点击“确认规则”后，页面进入规则已确认状态。
3. 已确认状态下显示两个开局动作：
   - “快速开局”: 使用已确认规则立即创建对局。
   - “自定义开局”: 带着已确认规则进入自定义开局，并跳过规则预设步骤。

这样避免用户在没有明确规则上下文时直接开局，也避免自定义开局重复选择同一条规则。

## 2. 现状

当前 `apps/mobile-web/src/pages/GameHomePage.tsx` 首页固定使用 `classic_12_seer_witch_hunter_idiot` 作为一键开局规则。自定义开局页 `CustomGamePage.tsx` 自己的第一步是“规则预设”，用户需要再次选择规则。

已有 API 能力满足本次需求：

- `listRuleSets()` 读取规则预设。
- `createGameRun()` 创建对局。
- `CustomGamePage` 已能根据规则人数限制玩家选择。

本次不需要修改后端接口。

## 3. 目标

- 首页必须先确认规则，才允许快速开局。
- 快速开局使用用户确认的 `rule_set_id`，不再写死规则。
- 自定义开局从首页进入时携带已确认规则，并直接进入“玩家选择”步骤。
- 自定义开局直接访问 `/custom-game` 时仍保留完整四步流程，从“规则预设”开始。
- 保留最近对局展示、开局错误提示和移动端竖屏布局稳定性。

## 4. 非目标

- 不新增后端字段或新 API。
- 不改变规则集定义、发牌逻辑、玩家档案数据结构或模型选择策略。
- 不重做玩家页、直播页、历史页或设置页。
- 不在本次引入默认规则本地存储；规则选择只作用于当前页面流程。

## 5. 首页交互

首页 `/` 分为三块：

1. 规则选择卡片
   - 使用 `listRuleSets()` 拉取规则。
   - 加载时显示读取提示。
   - 失败时显示错误状态。
   - 每条规则用现有移动端选择行展示名称、人数和角色摘要。
   - 默认选中第一条规则，但仍需要用户点击“确认规则”。

2. 已确认规则摘要
   - 用户确认后锁定当前规则。
   - 展示规则名称、人数和角色摘要。
   - 提供“更换规则”按钮，点击后回到可编辑选择状态，隐藏开局动作。

3. 开局动作
   - 未确认规则时只显示“确认规则”。
   - 已确认规则时显示“快速开局”和“自定义开局”。
   - “快速开局”调用：

```ts
createGameRun({
  max_rounds: 8,
  player_configs: [],
  rule_set_id: confirmedRule.id,
});
```

   - 创建成功后跳转 `/live/:runId`。
   - 创建失败沿用首页现有 `StatusBanner` 错误提示。
   - “自定义开局”跳转 `/custom-game?ruleSetId=<confirmedRule.id>`。

## 6. 自定义开局交互

`CustomGamePage` 读取 URL 查询参数 `ruleSetId`：

- 如果参数命中已加载的规则集，初始化为该规则，并从第 2 步“玩家选择”开始。
- 如果参数缺失，维持当前行为，从第 1 步“规则预设”开始。
- 如果参数存在但未命中规则集，维持从“规则预设”开始，并允许用户手动选择规则。

规则集数据是异步加载的，所以初始化逻辑必须在规则集加载完成后根据查询参数修正一次状态，且不能覆盖用户已经在页面内手动更改过的步骤或规则。

确认页中的规则、模型、最大轮数和玩家摘要沿用当前展示方式。提交请求继续使用 active rule 的 `id`。

## 7. 状态与错误

- 规则加载失败：禁止确认规则和快速开局，展示“规则读取失败”。
- 规则列表为空：展示空状态，禁止确认规则和快速开局。
- 开局进行中：禁用快速开局和更换规则，按钮显示“开局中...”。
- 自定义入口只在规则已确认后出现。
- 最近对局读取失败不影响规则选择和开局动作。

## 8. 测试

移动端测试覆盖：

- 首页加载规则后，未确认规则时不会显示快速开局动作。
- 选择并确认规则后，快速开局请求使用该规则的 `rule_set_id`。
- 首页自定义开局链接包含已确认规则的 `ruleSetId` 查询参数。
- `CustomGamePage` 带有效 `ruleSetId` 参数时直接显示“玩家选择”，并创建对局时使用该规则。
- `CustomGamePage` 无参数时仍从“规则预设”开始。
