# 实时导航设置弹窗设计

## 目标

实时观战页顶部导航需要进一步收敛信息层级：导航栏直接展示对局 ID 和观战状态，其他低频信息与控制项收进一个设置弹窗。用户在观看时应优先看到“我在哪一局、当前观战状态是什么”，需要操作时再从右侧设置入口打开控制面板。

## 范围

本设计只覆盖 `/games/live/:runId` 的顶部导航栏与其设置弹窗。

包含：

- 对局 ID 在导航栏中直接展示，并放在观战状态之前。
- `游戏规则` 从导航栏常驻区移入设置弹窗。
- `暂停/继续播放`、`追到最新`、`播放速度` 从导航栏中部控制区移入设置弹窗。
- `继续对局` 移入设置弹窗，并与播放控制互斥。
- `返回大厅` 移入设置弹窗。
- `查看完整复盘` 保持导航栏外部入口，不移入设置弹窗。
- 导航栏最右侧提供一个设置按钮作为弹窗入口。

不包含：

- 不改变实时事件流、导播播放算法、回放时间线、舞台布局或玩家状态。
- 不改变 `deriveLiveNavStatus` 的状态分类，只调整它在导航栏中的邻近信息。
- 不新增复杂偏好设置、持久化配置或快捷键系统。

## 导航栏信息架构

新的实时导航栏从左到右排列：

1. 品牌标识。
2. 对局 ID。
3. 观战状态。
4. `查看完整复盘`，仅在终局且已有复盘入口时显示，行为保持不变。
5. 设置按钮，固定为导航栏最右侧入口。

对局 ID 应使用等宽字体、可截断但可辨识的短标签。建议文案为：

- `对局 game_1200abcd`
- 或较窄屏下显示 `game_1200abcd`

观战状态继续使用当前合并后的状态胶囊，例如：

- `连接中`
- `直播中 · 1x`
- `追播中 · 落后 8 条 · 2x`
- `已暂停 · 落后 2 条`
- `异常中断 · 失败`
- `已结束 · 已完成`

导航栏不再常驻显示规则名、规则版本、玩家人数、暂停按钮、追进度按钮、速度选择或返回大厅。

## 设置按钮

设置按钮位于导航栏最右侧，使用图标按钮样式。

要求：

- `aria-label` 使用 `实时设置`。
- 按钮尺寸与现有导航图标按钮一致。
- 使用熟悉的设置图标；若当前图标库不可用，可先用文本符号或简洁字符实现，但最终 UI 应保持图标按钮语义。
- 弹窗打开后，焦点进入弹窗；关闭后焦点回到设置按钮。

## 设置弹窗结构

弹窗应是轻量级控制面板，而不是全屏页面。建议使用固定在右上角的浮层或带遮罩的小型 dialog。桌面端宽度建议约 `320-380px`；移动端可接近全宽但保留边距。

弹窗包含三个区块：

### 1. 对局信息

显示当前对局的基础上下文：

- 对局 ID。
- 当前观战状态。
- 当前规则名。
- 规则版本。
- 玩家人数。
- 有规则标签时展示规则标签。

规则摘要应简洁，不需要把完整角色配置重新塞回导航栏。若已有 `rule_set.role_summary`，可在弹窗中显示为一行或两行辅助信息。

### 2. 观战控制

该区域根据对局状态二选一展示。

正常观战状态下显示播放控制：

- `暂停` 或 `继续播放` 按钮，对应当前 `director.isPaused`。
- `追到最新` 按钮，对应 `director.catchUpToLatest`，在 `backlogCount === 0` 时禁用。
- `播放速度` 选择，保留 `1x` 与 `2x`。

失败且可继续状态下显示继续对局：

- `继续对局` 按钮，沿用现有 `resumeMutation` 行为。
- 按钮 pending 时显示 loading/disabled。
- 这时不显示 `暂停/继续播放`、`追到最新`、`播放速度`。

互斥规则：

- 当 `run.status === "failed"` 或收到 `game_failed` 终态事件时，显示 `继续对局`。
- 其他状态显示播放控制。
- `继续对局` 与 `暂停/继续播放` 永远不同时出现。

### 3. 导航操作

显示 `返回大厅`，行为等同当前 `/games` 链接。

`查看完整复盘` 不放在此区块，继续保留在导航栏中。原因是终局后复盘是强相关主操作，应该比设置弹窗更直接。

## 状态与数据流

保持现有底层状态不变：

- `useGameRunEvents` 继续负责连接与事件流。
- `useLiveDirector` 继续负责播放状态、暂停、追进度与速度。
- `deriveLiveNavStatus` 继续负责合并后的观战状态。
- `LiveGamePage` 负责把 `run`、`terminalEvent`、`director` 和导航操作传入新的设置弹窗组件。

建议新增或调整组件：

- `LiveNavSessionBadge`：渲染导航栏中的对局 ID。
- `LiveNavSettingsMenu`：渲染设置按钮与弹窗内容。
- 可复用或拆分 `LiveDirectorControls` 的内部控制逻辑，但导航栏中不再直接渲染 `LiveDirectorControls`。

现有 `RuleSetSummary` 可继续作为面板摘要使用，但导航栏版本不再常驻显示。弹窗可选择复用其数据格式，而不是直接复用当前导航样式。

## 交互细节

- 点击设置按钮打开弹窗。
- 点击关闭按钮、按 `Escape`、点击弹窗外部区域都应关闭弹窗。
- 弹窗中操作按钮点击后，弹窗可以保持打开；`返回大厅` 作为导航行为会离开当前页面。
- `追到最新` 在无 backlog 时禁用，并显示当前是否落后。
- 速度选择应显示当前值，选择后立即调用 `director.setSpeed`。
- 弹窗内容高度应适配小屏，必要时内部滚动。

## 错误与空状态

- `run` 未加载时不显示设置弹窗内容；设置按钮可不显示或禁用。
- 规则数据缺失时显示兜底名称 `实时对局`，不要让弹窗空白或报错。
- `resumeMutation` 失败时保留页面现有错误提示，同时弹窗中的 `继续对局` 按钮恢复可点击状态。
- 未知规则字段或未知状态字段不应阻塞弹窗渲染。

## 测试策略

新增或更新前端测试覆盖：

- 实时导航栏显示对局 ID，并且对局 ID 位于观战状态之前。
- 导航栏不再常驻显示规则摘要、暂停按钮、追到最新按钮、播放速度选择和返回大厅链接。
- 设置按钮位于导航栏操作区最右侧，且可打开设置弹窗。
- 弹窗中显示游戏规则信息。
- 正常观战状态下弹窗显示暂停/继续播放、追到最新和播放速度。
- 失败可继续状态下弹窗显示继续对局，不显示暂停/继续播放。
- `查看完整复盘` 仍保留在导航栏中，不进入设置弹窗。
- 返回大厅入口在弹窗中可见并指向 `/games`。

## 验收标准

- 导航栏主信息简化为对局 ID、观战状态、可选复盘入口、设置入口。
- 设置按钮在导航栏最右侧。
- 游戏规则、播放控制、继续对局、返回大厅都在设置弹窗中。
- 继续对局与播放控制按状态互斥。
- 查看完整复盘保持当前导航栏外部入口。
- 现有观战状态、舞台、时间线、玩家状态行为不变。
- 相关单元测试、页面测试、lint 与 build 通过。
